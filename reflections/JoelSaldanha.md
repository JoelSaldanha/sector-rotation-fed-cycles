## Learning integration

**MP1 flagged three issues that directly shaped how I worked here.** First, *"the -9999 values were not dealt with before aggregation"* — so [NB03](https://github.com/lse-ds105/group-project-git-it-done/blob/main/notebooks/NB03_analyse.ipynb) Section 3 now runs an explicit data-quality check (per-column nulls, per-sector observation counts, plausible-range sanity check) before any aggregation. The check confirmed zero nulls and surfaced one real coverage issue: XLRE has 124 observations versus 315 for every other sector, which became [Limitation 2 on the website](https://lse-ds105.github.io/group-project-git-it-done/#limitations). Second, *"your conclusion goes a little further than the mixed evidence shown in the notebook"* so the [website's Limitations section](https://lse-ds105.github.io/group-project-git-it-done/#limitations) includes a "What this analysis does not claim" callout, an explicit [Bottom Line](https://lse-ds105.github.io/group-project-git-it-done/#conclusion) that separates the descriptive finding from the causal claim, and a reframing in [Finding 3](https://lse-ds105.github.io/group-project-git-it-done/#finding-3) explaining that cutting-cycle outperformance is a recession story rather than a monetary easing story. Filing [Issue #9](https://github.com/lse-ds105/group-project-git-it-done/issues/9) on my own analysis was the same instinct: surface methodological limitations publicly rather than bury them. Third, *"you didn't notice you were supposed to move the notebooks to a dedicated folder called notebooks"*  so the [repository structure](https://github.com/lse-ds105/group-project-git-it-done) was planned before any notebook was written, with `notebooks/`, `data/raw/`, `data/processed/`, `docs/figures/`, and `reflections/` all in their proper places and documented in the [README](https://github.com/lse-ds105/group-project-git-it-done/blob/main/README.md).

**MP2 criticised that *"the collection date and key parameters are not consolidated as named variables at the top of NB01"*** so [NB03 Section 1](https://github.com/lse-ds105/group-project-git-it-done/blob/main/notebooks/NB03_analyse.ipynb) ("Decisions Made Before Writing Any Code") names and justifies every parameter and decision before the code that depends on it, in one location, and Section 10 exports the website's data as named JavaScript constants with comments pointing back to NB03 as the canonical source. I also carried forward what worked: MP2's praise for the explicit causal-disclaimer framing in Insight 2 became the model for the website's [What this analysis does not claim](https://lse-ds105.github.io/group-project-git-it-done/#limitations) callout and [Bottom Line](https://lse-ds105.github.io/group-project-git-it-done/#conclusion); the W04 practice feedback thanking me for sharing the AI chat log became the transparent model for this project's [public chat log](https://claude.ai/share/0fe1f266-9f36-4a10-81a6-a61b5351a76f) and "[About this site](https://lse-ds105.github.io/group-project-git-it-done/#build-notes)" disclosure. Naming what an analysis *cannot* claim, and being explicit about AI assistance scope, are habits I'm keeping.
